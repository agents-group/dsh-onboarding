命令会做什么（环境 Agent）

脚本是本地 playbook Agent（不是云端大模型）：多轮 观察 → 诊断 → 处置 → 复检，按机器现状选修复路径。

  1. 观察
    采集 OS、Node（^22.19 || >=24）、npm/npx、已有便携安装、凭据文件等事实。
  2. 诊断并自动修复
    缺 Node → 便携包/包管理器；PATH 坏了 → 修复；缺凭据 → 写入；同一修复失败则换策略或给出人工步骤。
  3. 写入默认配置
    Key → ~/.dsh/.credentials.yaml；端点 → ~/.dsh/.env。
  4. 启动 Web UI
    环境就绪后执行 npx -y @deepseek-ai/dsh web。
